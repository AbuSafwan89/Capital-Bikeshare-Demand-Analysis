# Capital-Bikeshare-Demand-Analysis
This code analyses the micro-mobility data from Washington, D.C. In consideration of different factors, this code conducts statistical analysis and forecasts the bike-share demand. 
Link to download the dataset: https://archive.ics.uci.edu/dataset/275/bike+sharing+dataset 
Key Features of the dataset: 
datetime: Hourly date + timestamp (YYYY-MM-DD HH:00:00) 
season: 1 = spring, 2 = summer, 3 = fall, 4 = winter 
holiday: Whether the day is considered a holiday (1 = holiday, 0 = non-holiday) 
workingday: Whether the day is neither a weekend nor holiday (1 = working day, 0 = weekend/holiday) 
Weather: 
1: Clear, Few clouds, Partly cloudy 
2: Mist + Cloudy, Mist + Broken clouds, Mist + Few clouds, Mist 
3: Light Snow, Light Rain + Thunderstorm + Scattered clouds, Light Rain + Scattered clouds 
4: Heavy Rain + Ice Pallets + Thunderstorm + Mist, Snow + Fog temp 
Temperature: in Celsius 
atemp: Feels like temperature in Celsius 
humidity: Relative humidity (%) 
windspeed: Wind speed
casual: Number of non-registered user rentals initiated
registered: Number of registered user rentals initiated
count: Number of total rentals (casual + registered)
